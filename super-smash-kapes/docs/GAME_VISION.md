# SUPER SMASH KAPES — Game Vision

Super Smash Kapes is a local couch multiplayer platform fighter inspired by the gameplay philosophy of Super Smash Bros. Four friends should be able to connect controllers, select absurd Paraguayan and South American characters, fight in recognizable regional locations, and laugh constantly.

M0 deliberately uses only readable placeholder capsules. Future fighters and stages can be absurd, culturally recognizable, and full of personality without changing the gameplay foundation.

## Philosophy

```text
FUN > REALISM
PERSONALITY > SERIOUSNESS
GAME FEEL > GRAPHICAL FIDELITY
COUCH MULTIPLAYER > ONLINE
CHAOS > PERFECT COMPETITIVE BALANCE
RESPONSIVENESS > PHYSICAL REALISM
DATA-DRIVEN DESIGN > HARDCODED CONTENT
```

The initial target is a Windows PC Godot 4.x game using GDScript, 3D rendering, 2.5D gameplay, 1920×1080 presentation, 60 physics ticks per second, and local multiplayer first.
